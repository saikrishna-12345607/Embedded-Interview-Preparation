## What I Understood

- Pointer is a variable that stores the memory address of another variable.
- '&' operator is used to get the address of a variable.
- '*' operator is used for pointer declaration and also to access the value stored at that address.
- NULL pointer points to nothing.
- Void pointer can store the address of any data type.
- Pointer arithmetic moves according to the size of the data type.
- Pointers are used to pass large data without copying it.
- In Embedded Systems, pointers are used to access hardware registers and memory mapped I/O.
