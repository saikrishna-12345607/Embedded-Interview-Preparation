# Day 7 - Unions in C

Today I learned about **Unions** in C programming.

At first, I thought Structure and Union were the same. After learning the concepts and writing the programs, I understood the main difference. A Union stores all members in the same memory location, so it saves memory.

## What I Understood

- A Union is a user-defined data type.
- All members share the same memory location.
- Only one member contains a valid value at a time.
- The size of a Union is equal to the size of its largest member.
- Unions are mainly used to save memory.
- In Embedded Systems, Unions are used in communication protocols and memory optimization.
