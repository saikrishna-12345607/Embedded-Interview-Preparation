What I Learned
Storage class controls the scope, lifetime and visibility of variables.
Auto is the default storage class for local variables.
Register requests faster access by using CPU registers.
Static keeps the variable value between function calls.
Extern is used to access the same global variable from different source files.
Static is widely used in Embedded Systems for counters, flags and state machines.
